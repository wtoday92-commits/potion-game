# Сборка

Проект собирается движком **Godot 4.7.1** (см. `config/features` в
`project.godot`). Шаблоны экспорта ставятся из редактора:
*Проект → Экспорт → Управление шаблонами → Скачать*.

## Веб (GitHub Pages)

```
Godot_v4.7.1-stable_win64_console.exe --headless --path . --export-release "Web" docs/index.html
```

Кладётся в `docs/`, оттуда Pages и раздаёт. Текущий вес: pck 38 МБ, wasm 38 МБ
(по сети ~10 МБ, Pages отдаёт wasm сжатым).

**Важно про фильтр ресурсов.** У пресета стоит `export_filter="all_resources"`
и менять это нельзя: игра грузит почти весь арт через `load()` по путям,
собранным в рантайме из id гостя и номера пассивки. Сканер зависимостей сцен
таких ссылок не видит и выкинет половину картинок.

**Важно про текстуры.** Всё тяжелее 40 КБ импортируется как Lossy WebP
(`compress/mode=1`, качество 0.85). Мелкие иконки и маски налива в
`assets/bottle` остались lossless — на маске артефакты сжатия пустили бы
жидкость мимо стекла. Новый крупный арт заводить сразу с lossy.

**Важно про музыку.** Треки — Ogg Vorbis ~65 kbps, звуковые эффекты — MP3
80 kbps моно. Vorbis на 65 kbps звучит не хуже прежних MP3 на 96 kbps и весит
на треть меньше. Зацикливание ставится в `Sfx._play_on`, там проверяются оба
типа потока.

## Android

Пресет `Android` в `export_presets.cfg` готов: портрет, только arm64,
иммерсивный режим, интернет для лидерборда. Но собрать пока нечем — в системе
нет ни шаблонов, ни SDK. Что нужно поставить:

1. **JDK 17** — например Temurin. Путь прописать в
   *Редактор → Настройки → Export → Android → Java SDK Path*.
2. **Android SDK** (командные инструменты + platform-tools + build-tools).
   Путь — там же, в *Android SDK Path*.
3. **Шаблоны экспорта Android** — те же, что для веба, ставятся вместе.

После этого:

```
Godot_v4.7.1-stable_win64_console.exe --headless --path . --export-release "Android" build/potion.apk
```

Для магазина понадобится свой keystore и `package/signed` с ним; сейчас пресет
рассчитан на отладочный ключ Godot.

Первый прогон на живом телефоне стоит считать отдельной задачей: тач-ввод,
вырез экрана и системная кнопка «назад» в вебе не проверяются никак.
